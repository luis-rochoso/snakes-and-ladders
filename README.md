# snakes-and-ladders
The classic snakes and ladders board game adapted as a videogame.
GUI modeled using the raylib library for C++.

# Compiling and running
You need **CMake** version 3.5 or higher to compile this game.

After navigating to the root of the project, compile with:
```
cmake -S . -B build

cmake --build build
```
Then, run the program with:
```
./build/snakesAndLadders
```

Have fun!
